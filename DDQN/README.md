# gym_super_mario

# **项目简介**

这个项目是我在学习强化学习过程中动手实践的一个成果，主要目标是利用强化学习算法让智能体（Agent）能够学会自动通关经典游戏《超级马里奥》。整个项目使用了 Python 语言，并基于 OpenAI 的 Gym 接口和 NES 游戏模拟器 `gym-super-mario-bros` 环境开发。在算法层面，我主要实现并调试了 DQN 和 DDQN 两种深度强化学习算法。

项目最核心的部分是实现了 DQN 和 DDQN 两套深度强化学习框架。从原始环境的像素画面出发，智能体在没有任何先验知识的前提下，通过与环境不断交互，逐步学会在游戏中生存、前进、跳跃、避障甚至击败敌人。

其中，我使用了经验回放机制（Replay Buffer）和目标网络（Target Network）以提高训练稳定性。此外，在 DDQN 的实现中引入了双网络分离更新的机制，有效缓解了 Q 值过估计的问题，使得训练更加稳定可靠。

# 一些处理

为了让神经网络更高效地学习，我对原始的游戏画面进行了图像预处理，包括：

* 跳帧处理（跳过冗余帧，加快训练速度）
* 灰度化（减少输入维度）
* 图像缩放（从 240x256 缩小至 84x84）
* 帧堆叠（Stack 4 帧，提供运动信息）

此外，我还自定义了奖励函数：除了游戏原有的奖励机制外，我额外增加了位置奖励（马里奥右移得分）、死亡惩罚、冲刺奖励等，用于鼓励马里奥尽量前进并完成关卡。

我手动定义了用于估计 Q 值的卷积神经网络（CNN），包括 3 层卷积 + 2 层全连接网络。输入为处理后的 4 帧图像，输出为对应动作空间的 Q 值估计。神经网络结构参考了 Nature DQN 的经典配置，并做了适当简化以适配马里奥游戏的帧率和图像复杂度。

为了能更好地观察训练过程和策略演化，我还实现了如下可视化工具：

* **训练奖励曲线绘制** ：记录每一回合的总奖励，动态绘图展示智能体学习进度。
* **GIF 动画记录** ：在训练过程中记录最优表现的游戏片段，并保存为 gif，便于直观展示马里奥的表现。
* **断点续训机制** ：支持模型保存与加载，避免每次训练都要从头开始，提高实验效率。
* 最终训练出来的智能体能够在训练环境中成功通关简单的游戏关卡（例如 Level 1-1），并能够较为灵活地避开障碍物、跳跃蘑菇敌人、选择合适的前进节奏。虽然在复杂关卡中仍有改进空间，但项目整体展现了强化学习从零开始学习复杂任务的能力。

# 结论

最终训练出来的智能体能够在训练环境中成功通关简单的游戏关卡（例如 Level 1-1），并能够较为灵活地避开障碍物、跳跃蘑菇敌人、选择合适的前进节奏。虽然在复杂关卡中仍有改进空间，但项目整体展现了强化学习从零开始学习复杂任务的能力。、
