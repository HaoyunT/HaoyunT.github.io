## 🚀 快速开始

1. **克隆仓库**
   ```bash
   git clone https://github.com/HaoyunT/HaoyunT.github.io.git
   ```

2. **添加缺失文件**
   - 将论文PDF文件放入 `paper/` 目录
   - 将大学校徽图片放入 `images/` 目录

3. **本地预览**
   ```bash
   # 使用Python启动本地服务器
   cd HaoyunT.github.io
   python -m http.server 8000
   ```
   然后打开浏览器访问 http://localhost:8000

4. **部署到GitHub Pages**
   - 推送代码到main分支
   - 在GitHub仓库设置中启用Pages功能

## 🔧 自定义指南

### 更新个人信息
在 `index.html` 中修改相应的个人信息、联系方式和社交链接。

### 添加新论文
1. 将PDF文件添加到 `paper/` 目录
2. 在HTML中的publications部分添加新的论文条目

### 修改主题样式
在 `styles.css` 中可以调整：
- 主色调：修改 `#667eea` 和 `#764ba2`
- 字体：更改 `font-family` 属性  
- 布局：调整 grid 和 flexbox 参数
